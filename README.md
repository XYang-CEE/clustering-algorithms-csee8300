# Clustering Algorithms (CSEE / ENGR 8300)

Notebook and slides on clustering algorithms.

| File | Content |
|---|---|
| `Clustering_Lecture.ipynb` | Clustering principles worked by hand on toy data (distance, k-means, elbow and silhouette, hierarchical clustering, DBSCAN, Gaussian mixtures) and a comparison of algorithms on different data shapes. |
| `Clustering_Lecture_Slides.pdf` | Slides. |

Run the notebook with Python 3 and `numpy`, `pandas`, `matplotlib`, `scipy`, `scikit-learn`.
